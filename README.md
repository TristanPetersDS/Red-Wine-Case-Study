# Springboard Regression Case Study - Red Wine Dataset

## Project Overview
This project is part of the Springboard Regression Case Study (Tier 3). The goal is to apply regression analysis techniques to predict alcohol levels in red wine using exploratory data analysis (EDA) and machine learning models.

## Dataset
The dataset used in this project is the **Red Wine Quality Dataset** from Kaggle. It includes various chemical properties of red wine samples, which are used as features to build predictive models.

## Methodology
1. **Data Exploration & Cleaning**:
   - Loaded and examined the dataset.
   - Checked for missing values and performed necessary preprocessing.
   
2. **Exploratory Data Analysis (EDA)**:
   - Visualized feature distributions.
   - Analyzed correlations between variables.
   
3. **Regression Modeling**:
   - Built and evaluated multiple regression models, including:
     - **Univariate Linear Regression**
     - **Ordinary Least Squares (OLS) Regression**
     - **Multiple Linear Regression**
     - **Feature Selection to Avoid Redundancy**
   
4. **Model Evaluation**:
   - Used metrics such as **Mean Squared Error (MSE)** and **R-squared (R²)** to assess model performance.
   
## Key Findings
- Identified key features that influence alcohol content in red wine.
- Compared multiple regression models to determine the best-performing approach.
- Demonstrated the importance of feature selection in improving model accuracy.
